# ひらがなIME（Android版）

Android用の日本語入力アプリです。  
ひらがなで入力し、あとから漢字に変換できます。

## 特長

- ひらがなで入力し、すきなタイミングで漢字に変換できます。  
- ならった漢字だけに変換できるので、学年にあわせた入力が可能です。  
- おくりがなのある言葉も、簡単に変換できます。  
- ローマ字入力とフリック入力の両方に対応しています。  
- インターネットに接続せず、端末内ですべての処理をおこないます。

## 使いはじめる

1. 「ひらがなIME」をインストールします（配布の方法はあとで書く）。  
2. アプリをひらき、「設定をひらく」をおして「ひらがなIME」を有効にします（端末によって、設定の画面の名前はちがいます）。  
3. 「キーボードをえらぶ」をおして、「ひらがなIME」をえらびます。

## 打ち方

「かんじ」を「漢字」に変換する例：  
「かんじ」と入力し、［変換］キーを押すと「漢字」になります。  

「書く」をおくりがなで変換する例：  
「か」と入力し、［送り］キーを押し、続けて「く」と入力すると「書く」になります。  

詳しい使い方は [docs/usage.md](docs/usage.md) を参照してください。

## キー

| キー | なにをするか |
|------|--------------|
| 変換 | カーソルの前のひらがなを漢字にする。もう一度押すと、次の候補になる |
| 確定 | いまの候補できめる。候補がないときは改行 |
| 送り | おくりがなのある言葉（「書く」「起きる」など）を変換するときにつかう |
| ←境界 / 境界→ | 変換するながさをかえる。おもったところで区切られなかったときにつかう |
| カナ | カーソルの前のひらがなを、1字ずつカタカナにする（押すたびに1字ふえる） |
| ゛゜小 | 12キーで、前の字に濁点・半濁点をつけたり、ちいさい字にしたりする |
| あ/A | ひらがなと英字をきりかえる |
| ⌫ | 1字けす。押しつづけるとつづけてきえる |

## 設定

- はじめのモード（ひらがな／英字）  
- 漢字の範囲（小学1年〜6年、中学、高校、一般）  
- 許容のおくり仮名もつかう（一般のときだけ）  
- 数字を半角にする  
- 「nn」で「ん」にする  
- ユーザー辞書：自分で言葉をたせる（名前、学校の名前など）  
- 学習をリセット

## プライバシー

アプリはインターネットに接続しません。  
うった文字や学習の記録は、端末内のみに保存されます。  
広告や利用状況の収集は行っていません。  
詳細は [docs/privacy.md](docs/privacy.md) を確認してください。
