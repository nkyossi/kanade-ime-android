# ひらがなIME Android版 — 事実シート（Sarashina のプロンプトに貼る）

作成日：2026-10-16。機能を変えたら、ここを直してから各プロンプトに貼り直してください。

## なにか

- Android のキーボード（入力方法）。名前は「ひらがなIME」。
- Esrille（エスリル）社の「Hiragana IME」（Linux 用、Apache License 2.0）を Android に移したもの。Esrille 社の公式のものではない（非公式の移植）。
- 変換のしくみは、同じ作者が先に作った Windows 版（Hiragana IME for Windows、非公式）と同じプログラムを使っている。

## いちばんの特長：ひらがなで書いて、あとから漢字にする

- ふつうのキーボードは、打つたびに変換の候補が出てくる。ひらがなIMEは、**打った字はそのまま、ひらがなで入る**。
- 漢字にしたいところまで打ったら、［変換］キーを押す。すると、カーソルのすぐ前のひらがなが漢字になる。
- 漢字にしなければ、ひらがなのまま。ひらがなだけで書く小さい子どもでも使える。
- **習った漢字だけに変換できる**：「漢字の範囲」の設定で、小学1年〜6年、中学、高校、一般（常用漢字）から選べる。たとえば「小学2年」にすると、2年生までに習う漢字しか出てこない。習っていない字は、ひらがなのまま残る。

## キーボードの種類

- **ローマ字（QWERTY）**：パソコンと同じ並び。`k` `a` で「か」。
- **12キー（フリック）**：スマホでよく使う並び。「あ」のキーを左に払うと「い」、上で「う」、右で「え」、下で「お」。
- 12キーでは［123］のキーを右に払うと ABC（ローマ字）に、ローマ字では［あ/A］のキーを上に払うと12キーに切り替わる。

## 特別なキー

| キー | なにをするか |
|---|---|
| 変換 | カーソルの前のひらがなを漢字にする。もう一度押すと、次の候補になる |
| 確定 | いまの候補で決める。候補がないときは改行 |
| 送り | 送りがなのある言葉（「書く」「起きる」など）を変換するときに使う。「か」と打って［送り］を押し、続けて「く」と打つと「書く」になる。ローマ字のキーボードでは［変換］を上に払う |
| カナ | カーソルの前のひらがなを、カタカナにする |
| ゛゜小 | 12キーで、前の字に濁点・半濁点をつけたり、小さい字にしたりする（か→が、は→ば→ぱ、つ→っ→づ） |
| あ/A | ひらがなと英字を切り替える |
| ⌫ | 1字消す。押し続けると続けて消える |
| ペースト | コピーした文字を入れる（12キー） |
| カーソル | タップで左へ、右に払うと右へ、カーソルを動かす（12キー） |

- 候補はキーボードの上の列に並ぶ。タップして選べる。
- 候補の列には、変換する長さを短くした候補も、うしろに並ぶ。たとえば「きょうは」で［変換］を押すと「右派」のあとに「う羽」「う歯」…が並ぶ。思ったところで区切られなかったときは、これを選ぶ。
- 選んだ候補は覚えておき、次から先に出る（学習）。学習は設定から消せる。

## 設定

- はじめのモード（ひらがな／英字）
- 漢字の範囲（小学1年〜6年、中学、高校、一般）
- 許容の送り仮名も使う（一般のときだけ）
- 数字を半角にする
- 「nn」で「ん」にする
- ユーザー辞書：自分で言葉を足せる（名前、学校の名前など）
- 学習をリセット

## プライバシー

- インターネットにつながない（アプリに通信の権限がない）。
- 打った文字、学習の記録、ユーザー辞書は、すべて端末の中だけに保存する。外に送らない。
- 広告なし、利用状況の収集（アナリティクス）なし。
- パスワードの欄では、はじめから英字になる。パスワードの欄で打った文字は学習しない。

## 動く環境

- Android 8.0 以上。
- アプリの大きさ：辞書を含めておよそ 10MB（あとで正確な値を入れる）。
