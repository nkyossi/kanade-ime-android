## 書き方

- です・ます調。
- 1文を短く（40字くらいまで）。
- 宣伝の言葉（「画期的」「最高の」など）は使わない。事実だけを書く。
- 事実シートに書いていないことは書かない。分からないところは `（あとで書く）` と書いて空けておく。
- Markdown。見出しは `##` から。表は使ってよい。絵文字は使わない。

## 構成（この順番で）

1. `# ひらがなIME（Android版）` と、1〜2文の説明
2. `## 特長`：箇条書き3〜5個。「ひらがなで書いて、あとから漢字にする」と「習った漢字だけに変換できる」を必ず入れる。
3. `## 使いはじめる`：アプリを入れてから、キーボードを有効にして、切り替えるまでの手順を、番号つきで。
4. `## 打ち方`：「かんじ」を打って「漢字」に変換する例と、「書く」を送りがなで変換する例を、キーの押し方の順に。くわしい使い方は `docs/usage.md` にある、と書いてリンクする。
5. `## キー`：特別なキーの表（事実シートの表をもとに）。
6. `## 設定`：設定の項目の箇条書き。
7. `## プライバシー`：3〜4行。くわしくは `docs/privacy.md` へリンク。
8. `## ライセンス`：アプリ本体と辞書のライセンスを表で。Esrille 社の公式のものではないこと、ロゴを使っていないことも書く。
9. `## 謝辞`：Esrille 社の Hiragana IME、SKK 辞書、EDICT への感謝を1〜2文で。
