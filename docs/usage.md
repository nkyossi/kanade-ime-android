# ひらがなIMEのつかいかた

## このキーボードのとくちょう

このキーボードでは、はじめにひらがなで文字をうちます。

あとから漢字にかえることもできます。

変換するときには、あなたがならった漢字だけがでます。

## ひらがなをうつ

### ローマ字（QWERTY）

パソコンとおなじならびです。

「か」は `k` と `a` をおします。

「が」は `g` と `a` をおします。

### 12キー（フリック）

「あ」のキーをはらうと、ほかの字がでます。

- そのままおすと「あ」
- 左にはらうと「い」
- 上にはらうと「う」
- 右にはらうと「え」
- 下にはらうと「お」

ほかのキーもおなじです。「か」のキーを左にはらうと「き」、下にはらうと「こ」がでます。

## 漢字にかえる

たとえば、「かんじ」を漢字にかえてみましょう。

1. 「かんじ」とうちます。
2. ［変換］をおします。
3. キーボードの上に漢字の候補がでます。
4. もういちど［変換］をおすと、つぎの候補がでます。
5. つかいたい漢字がでたら、［確定］をおします。

## おくりがなのあることば

「書く」をうつときは、つぎのようにします。

1. 「か」とうちます。
2. ［送り］をおします。
3. つづけて「く」とうちます。

これで「書く」になります。

## ことばがうまくわかれないとき

［変換］をおすと、カーソルのすぐ前から、辞書にあるいちばん長いことばをさがして漢字にします。
そのため、思ったところでわかれないことがあります。

たとえば「きょうは」とうって［変換］をおすと、「きょ右派」になります。

- ［←境界］をおすと、変換する長さがみじかくなります。「きょう羽」になります。
- ［境界→］をおすと、もとの長さにもどります。

いちばんかんたんなのは、ことばごとに変換することです。

1. 「きょう」とうちます。
2. ［変換］をおすと「今日」になります。
3. ［確定］をおしてから、「は」とうちます。

## カタカナにかえる

「テレビ」をうつときは、つぎのようにします。

［カナ］をおすと、カーソルのすぐ前の字から、1字ずつカタカナになります。

1. 「てれび」とうちます。
2. ［カナ］を1回おすと「てれビ」、2回で「てレビ」、3回で「テレビ」になります。
3. ［確定］をおします。

## 「が」や「っ」をうつ（12キー）

### 「が」をうつ

1. 「か」をうちます。
2. ［゛゜小］をおします。

これで「が」になります。

### 「っ」をうつ

1. 「つ」をうちます。
2. ［゛゜小］をおします。

これで「っ」になります。もう1回おすと「づ」、もう1回で「つ」にもどります。

## こまったとき

- **ならっていない漢字をつかいたい**

  おうちの人や先生に、設定の「漢字の範囲」をかえてもらいましょう。

- **まちがえて変換した**

  ［⌫］をおすと、文字をけせます。

- **カタカナが1字しかならない**

  ［カナ］は1回で1字ずつです。カタカナにしたい字の数だけおしましょう。

- **英字をうちたい**

  ［あ/A］をおしましょう。

- **学習したことを消したい**

  設定から「学習をリセット」をえらびましょう。

## おうちの方・先生へ

このアプリでは、子どもの学習段階に合わせて、漢字の変換範囲をかえられます。

設定の「漢字の範囲」から、学年に合わせた漢字の制限をえらべます。

ユーザー辞書に名前や学校名を登録すると、固有名詞もかんたんにうてます。

学習データのリセットや、半角数字への変換にも対応しています。学校や家庭での学習にあわせておつかいください。

このアプリは通信をおこないません。入力したデータや学習データは、すべて端末のなかに保存されます。
